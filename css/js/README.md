# Pomodoro+ Focus Timer

A clean, feature-rich Pomodoro timer to help you stay focused and productive.

## Features

- **Three session modes** — Focus (25 min), Short Break (5 min), Long Break (15 min)
- **Animated progress ring** — visual countdown that drains as time passes
- **Session stats** — tracks completed pomodoros, total focus time, and your streak
- **Task list** — add tasks, mark them complete, delete them

## Getting Started

No dependencies. Just open `index.html` in your browser.

```bash
git clone https://github.com/yourusername/pomodoro-plus.git
cd pomodoro-plus
open index.html
```
